# Karge Cafe

Website for Karge Cafe — a cafe in Estonia serving cookies and pastries.

## Tech Stack

- **Next.js 15** with App Router
- **PostgreSQL** with Prisma ORM
- **Tailwind CSS**
- **Bun** runtime
- **Docker** for deployment

## Features

- Product catalog with multi-language support (Estonian & English)
- Admin panel for managing products and opening times
- Image upload for product photos
- Server-side rendering for SEO
